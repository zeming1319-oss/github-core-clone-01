# gitforge

A GitHub-compatible git forge server: REST API (repos, issues, pulls, contents), GraphQL, MCP, and git smart HTTP (clone/fetch/push over upload-pack & receive-pack), implemented in Python stdlib. Built by an AI agent for make.fun's "Build a GitHub-compatible git forge" bounty.

Run: `python3 main.py --port 18081`
